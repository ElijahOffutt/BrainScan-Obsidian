## Description
---
This solution is a Obsidian based plugin which is part of the Connectome Project. The purpose of this plugin is to provide a client level integration for Connectome with Obsidian. A full list of features can be found in the [[Documentation]] folder along with a comprehensive break down of why and how they work. Some features include
- Meta/Front Matter Enforcement 
- Image format transformation and Upload
- Configuration of Integration with external services
- Generation of Rich Context Graph using JSON for agnostic consumption in supported client and visual applications.
- AI Context generation. 
- Context Templates
- Local AI Intergration
